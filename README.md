# FPS 5:5 Team Battle

Three.js로 만든 3D 5:5 팀 전투 시뮬레이션 (폐허가 된 도시 배경).

## 실행
- `index.html` (또는 `fps-game.html`)을 브라우저로 열기
- 인터넷 연결 필요 (Three.js를 unpkg CDN에서 로드)

## 조작
| 키 | 동작 |
|---|---|
| WASD | 이동 |
| 마우스 | 시점 |
| 좌클릭 | 사격 (M4A1은 자동) |
| R | 재장전 |
| Shift | 달리기 |
| Space | 점프 |
| 1 / 2 | 무기 변경 (M4A1 돌격소총 / M1911 권총) |

## 게임 규칙
- 아군 5명(파랑) vs 적군 5명(빨강)
- 아군 본인은 1인칭, 나머지는 AI
- AI는 엄폐물을 활용해 전투
- 머리 명중 시 2배 데미지
- 사망 시 5초 후 팀 진지에 부활, 3초간 무적 보호막

## 데미지
| 무기 | 몸통 | 머리 |
|---|---|---|
| M4A1 | 25 | 50 |
| M1911 | 15 | 30 |
| AI | 10 | 20 |
